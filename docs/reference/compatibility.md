# Compatibility

Python 3.11 and 3.12: supported candidate targets; package metadata excludes Python 3.13 until that runtime is added to CI. Python library and local JSON CLI: supported. Controlled session export: supported format. Hermes Agent 0.19.1 at exact official revision `0a62610f10cc34d696b2239b2c69fa1ba0f1ca63`: maintained optional reference adapter target. Obsidian: controlled import and derived projection. Other Hermes versions, named harnesses, and MCP clients are integration patterns until separately tested.

No hosted service or remote API compatibility is claimed.
